# Python Generators
- Generator functions return a _generator object_, which is an iterator
- A _generator object_ can stop and later resume working
- Generators use the __yield__ keyword (instead of __return__)

## Comparison
Regular function:
```python
def my_func():
    value = 1
    print("Hello World")
    return value
    # Any code after the return statement will not be executed:
    print("John Doe")
```
Generator:
```python
def my_gen():
    yield "Hello"
    yield "Big"
    yield "World"
```

## The generator object
- Calling then function will not run the code within
- It only returns a _generator object_
- It only runs the code "when asked"
```python
def my_gen():
    yield "Hello"
    yield "Big"
    yield "World"

gen_obj = my_gen()
print(type(gen_obj))
```
Output:
```
<class 'generator'>
```

## Manual Usage
```python
def my_gen():
    yield "Hello"
    yield "Big"
    yield "World"

gen_obj = my_gen()
first_value = next(gen_obj)
print(first_value)
```

- In the above code we created a generator object, __gen_obj__, which is an iterator
- Then we started iterating through it with the __next()__ function
- __next()__ tells the generator to start running until it reaches the first yield
- The generator hands back the value at the first __yield__, which is "Hello" and pauses there
- You can manually iterate over a generator:

```python
def my_gen():
    yield "Hello"
    yield "Big"
    yield "World"

gen_obj = my_gen()
print(next(gen_obj))
print(next(gen_obj))
print(next(gen_obj))
```

### Stop iteration
- If you try to iterate over the last element, you will get a __StopIteration__ error:

```python
def my_gen():
    yield 1
    yield 2

gen_obj = my_gen()
print(next(gen_obj))
print(next(gen_obj))
print(next(gen_obj))
```

- Output:
```python
1
2
StopIteration
```

## Loop over an iterator
- Calling _next()_ one-by-one is tedious and runs the risk of getting a __StopIteration__ error
- Better to iterate over a generator in a _for_ loop
- The _for_ loop automatically calls the _next()_ function at each iteration
- The _for_ loop also automatically exits after the last value

```python
def my_gen():
    yield 1
    yield 2

gen_obj = my_gen()
for value in gen_obj:
    print(value)
```
- Compare previous with below example, they both work
```python
def my_gen():
    yield 1
    yield 2

gen_obj = my_gen()
for value in my_gen():
    print(value)
```

## Cast iterator to a list
- After a generator yields a value, it does not store it, you cannot ask for it again
- If you need the full list of values, generated by a generator, at once, cast a generator to a list:
```python
list(my_gen())
```
- This will return a list of all the items

## Generator expressions
- You can create generators using generator expressions

```python
gen_exp = (x * x for x in range(5))
print(gen_exp)
print(list(gen_exp))
```
- Output:
```
<generator object <genexpr> at 0x...>
[0, 1, 4, 9, 16]
```

## Why use generators?
- Generators are memory-efficient because they generate values on-the-fly instead of storing everything in memory
- Below example generates values on the fly, does not store everything in memory
- Generators are modular and resuable

```python
def large_sequence(n):
  for i in range(n):
    yield i

# This doesn't create a million numbers in memory
gen = large_sequence(1000000)
print(next(gen))
print(next(gen))
print(next(gen))
```

## How to find primes with a generator?
- This is an example on how and for what to use generators
- First, here is a solution __without__ generators:
- This is called __eager evaluation__, because it does everything at once
```python
# Find prime numbers without using generators
def get_primes_list(start, end):
    primes = []
    for num in range(start, end + 1):
        if num < 2:
            continue
        is_prime = True
        for i in range(2, num):
            if num % i == 0:
                is_prime = False
                break
        if is_prime:
            primes.append(num)
    return primes

get_primes_list(50, 100)
```
- Now a solution using a generator:
- This is called __lazy evaluation__ because it only works when asked to
```python
# Find primes using a generator
def gen_primes(start, end):
    for num in range(start, end + 1):
        if num < 2:
            continue
        is_prime = True
        for i in range(2, num):
            if num % i == 0:
                is_prime = False
                break
        if is_prime:
            yield num

gen_primes_object = gen_primes(50, 100)
print(next(gen_primes_object))

for num in gen_primes(50, 100):
    print(value)
```

## Fibonacci number generator
- Get the first 100 Fibonacci numbers:
```python
def fibonacci():
  a, b = 0, 1
  while True:
    yield a
    a, b = b, a + b

gen = fibonacci()
for _ in range(100):
  print(next(gen))
```

## Generator methods
- Generators have special methods for advanced control

### send()
- You can send a value to a generator

```python
def echo_generator():
  while True:
    received = yield
    print("Received:", received)

# Create the generator object
gen = echo_generator()
# Prime the generator
next(gen)
# Send a value to the generator
gen.send("Hello")
gen.send("World")
```
- Output:

```python
Received: Hello
Received: World
```

### close()
- You can stop a generator from working

```python
def my_gen():
  try:
    yield "Hello"
    yield "World"
  finally:
    print("Generator closed")

gen = my_gen()
print(next(gen))
gen.close()
```
- Output:

```python
Hello
Generator closed
```
